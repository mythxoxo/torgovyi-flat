# Code of Conduct

## Our pledge

Project participants are expected to keep collaboration focused, respectful, and useful for the project.

## Expected behavior

- Use clear technical feedback.
- Keep discussions relevant to the repository.
- Report security issues privately through `SECURITY.md`.
- Avoid publishing private keys, mnemonics, tokens, or sensitive deployment data.

## Unacceptable behavior

- Harassment or personal attacks in project spaces.
- Spam or off-topic promotion.
- Public disclosure of vulnerabilities or secrets before maintainer review.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that break these rules. Repeated abuse may lead to blocking from the repository.
