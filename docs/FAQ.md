# FAQ

## Is it live?
No. Live proof is still pending manual wallet signing and funded test wallets.

## Is it custodial?
No. The prepared path is manual no-custody signing through wallet flow.

## Why 5 TON now and 8888 TON later?
5 TON is a temporary test target for first live-proof passes. 8888 TON remains the production target.

## What is verified?
Contracts build, contract verification, sandbox buy/mint loop, security check, build, and TonConnect payload generation.

## What is not verified?
Live deploy, live buy, live buyer Jetton balance, live migration listing, live LP lock proof, live indexer DB proof.

## What happens after token graduation?
The product is designed to move toward post-migration listing flow after graduation, but live listing proof is still pending.

## Can users lose funds?
Yes. This is a high-risk meme-token system. No live-proof means operational risk remains until manual mainnet validation is completed.

## What prevents fake balances?
Blockchain state is the source of truth, indexer is cache only, and fake balance/stat regressions are guarded by code and security checks.

## What still needs live proof?
Funded wallets, signed mainnet transactions, buyer Jetton receipt on chain, indexer DB proof, and live migration path proof.
